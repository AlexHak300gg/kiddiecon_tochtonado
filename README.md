# KiddieCoin - Приложение для обучения финансовой грамотности

**KiddieCoin** — это Flutter-приложение для родителей и детей, которое помогает обучить финансовой грамотности через игровую систему сбережений, создание целей и выполнение задач. Приложение построено на Firebase Realtime Database с поддержкой real-time синхронизации данных.

## 💰 Виртуальные счета

### Модель счета (`lib/models/account.dart`)
- **Поля**: balance (баланс), dailyRate (дневная ставка), lastCalculatedAt (дата последнего расчета), updatedAt (дата обновления)
- **Методы**: toJson, fromJson, copyWith

### Модель операции (`lib/models/operation.dart`)
- **Поля**: type (тип), amount (сумма), reason (причина), timestamp (время), balanceBefore (баланс до), balanceAfter (баланс после)
- **Типы операций**: daily_interest, transfer, task_reward, goal_deposit, goal_withdrawal

### Сервис счета (`lib/services/account_service.dart`)
- ✅ Real-time потоки баланса и истории операций
- ✅ Локальное кэширование в JSON файлах
- ✅ Синхронизация с Firebase
- ✅ Автоматический расчет ежедневного процента
- ✅ Компенсация за пропущенные дни при открытии приложения
- ✅ Firebase транзакции для атомарных операций

### Ежедневные проценты (`lib/services/daily_interest_service.dart`)
- ✅ Background task через Android AlarmManager (каждые 45 минут)
- ✅ Фоллбек-таймер для iOS/web/desktop и на случай ошибок планировщика
- ✅ Автоматический расчет в 00:00 (только один раз в день)
- ✅ Формула: new_balance = current_balance * (1 + daily_rate)
- ✅ Дневная ставка = годовая ставка / 365
- ✅ Логирование каждого начисления процентов
- ✅ Компенсация для пропущенных дней

### Экран истории операций (`lib/screens/operation_history_screen.dart`)
- ✅ Полная история всех операций
- ✅ Информация о каждой операции: тип, сумма, причина, время
- ✅ Отслеживание баланса в каждый момент времени
- ✅ Фильтрация по типам операций
- ✅ Статистика по видам доходов

### Управление процентной ставкой
- ✅ Родитель может устанавливать ежегодную процентную ставку (0-100%)
- ✅ Изменения применяются к будущим расчетам
- ✅ Реальная валидация
- ✅ По умолчанию: 0.01% годовых

### Firebase структура счетов
```
/children/{childId}/account
  ├── balance: 1000.00
  ├── dailyRate: 0.0001
  ├── lastCalculatedAt: "2024-01-01T00:00:00.000Z"
  └── updatedAt: "2024-01-01T12:00:00.000Z"

/children/{childId}/history/{operationId}
  ├── type: "daily_interest"
  ├── amount: 0.10
  ├── reason: "Ежедневный процент за 01.01.2024"
  ├── timestamp: "2024-01-01T00:00:00.000Z"
  ├── balanceBefore: 1000.00
  └── balanceAfter: 1000.10
```

## 🔗 Привязка родитель-ребенок через QR код

### Функциональность
- ✅ Родитель генерирует 8-символьный код приглашения
- ✅ Вывод QR-кода с кодом для сканирования
- ✅ Возможность копирования кода в буфер обмена
- ✅ Ребенок может отсканировать QR-код или ввести код вручную
- ✅ Двусторонняя привязка: родитель видит ребенка и наоборот
- ✅ Максимум 5 детей на родителя

### Особенности кода приглашения
- ✅ Длина: 8 символов
- ✅ Символы: A-Z, 2-9 (исключены O/0, I/1, L для читаемости)
- ✅ Уникальность: автоматическая регенерация при совпадении
- ✅ Срок действия: 24 часа
- ✅ Однократное использование

### Экраны QR функционала
- ✅ `invite_dialog_screen.dart` - генерация и отображение QR-кода для родителя
- ✅ `qr_scanner_screen.dart` - сканирование QR-кода ребенком

### Валидация кода
1. ✅ Код существует в базе данных
2. ✅ Код не использован
3. ✅ Код не истек (не старше 24 часов)
4. ✅ Родитель существует в базе
5. ✅ У родителя менее 5 детей
6. ✅ Диалог подтверждения перед привязкой

### Обработка ошибок
- ✅ Код не найден
- ✅ Код истек (с автоматической очисткой)
- ✅ Код уже использован
- ✅ Родитель не найден
- ✅ Родитель при максимальном количестве детей

### Firebase структура кодов приглашений
```
/inviteCodes/{CODE}
  ├── parentId: "firebase-parent-id"
  ├── parentKey: "parent@example.com"
  ├── parentName: "parent@example.com"
  ├── createdAt: "2024-01-01T12:00:00.000Z"
  ├── expiresAt: "2024-01-02T12:00:00.000Z"
  ├── isUsed: false
  ├── usedBy: "child-id" (при использовании)
  └── usedAt: "timestamp" (при использовании)
```

### Используемые пакеты
- ✅ `qr_flutter` (^4.1.0) - генерация QR-кодов
- ✅ `mobile_scanner` (^5.2.3) - сканирование QR-кодов

### Платформо-специфичные настройки
- ✅ **Android**: CAMERA permission в AndroidManifest.xml
- ✅ **iOS**: NSCameraUsageDescription в Info.plist

## 🏗️ Технические детали

### Архитектура

#### Service Layer (Сервисный слой)
- Singleton сервисы для управления бизнес-логикой
- Real-time потоки (Streams) для обновления UI
- Firebase транзакции для атомарных операций
- Локальное кэширование для offline режима

#### Model Layer (Слой моделей)
- Классы данных с методами сериализации (toJson/fromJson)
- Вычисляемые свойства для логики представления
- CopyWith методы для неизменяемости

#### UI Layer (Слой представления)
- StreamBuilder для реактивных обновлений
- Proper cleanup в dispose методах
- Mounted checks перед использованием BuildContext
- Ошибка обработка с SnackBar уведомлениями

### Real-time синхронизация
1. Firebase изменяет данные
2. Listener в сервисе получает событие
3. Сервис парсит и кэширует данные
4. Обновление отправляется в Stream
5. UI компоненты (StreamBuilder) автоматически обновляются

### Валидация данных
- Валидация на уровне UI (диалоги, формы)
- Валидация на уровне сервиса (перед Firebase)
- Firebase правила безопасности

### Обработка ошибок
- Try-catch блоки для async операций
- User-friendly сообщения об ошибках
- SnackBar уведомления
- Автоматические повторные попытки где необходимо

### Производительность
- Broadcast потоки для множественных подписчиков
- Efficient Firebase listeners (один на сервис)
- Кэширование данных
- Lazy loading для больших списков

### Локализация
- Русский язык для всех текстов
- Форматирование дат и чисел через intl пакет
- Локализованные календари для date picker'ов

При переходе на новые версии приложения пользователям может потребоваться пересоздать цели, так как старая структура данных используется в legacy узлах.

Приложение требует следующей структуры в Firebase:

- Коллекция `/children` для данных детей (счета, история)
- Коллекция `/tasks` для задач
