# Реализация модуля целей с Firebase синхронизацией

## Обзор реализации

Модуль целей был полностью переработан с заменой stub-реализации на полнофункциональную систему с реальной Firebase синхронизацией в реальном времени.

## Что было реализовано

### 1. Модель данных (`lib/models/goal.dart`)

**Структура Goal:**
- `id` - уникальный идентификатор
- `name` - название цели
- `target` - целевая сумма в рублях
- `progress` - накопленная сумма
- `active` - флаг активности (только одна активная цель одновременно)
- `createdAt` - дата создания
- `completedAt` - дата завершения (опционально)
- `deadline` - срок достижения цели (опционально)

**Вычисляемые свойства:**
- `remaining` - осталось накопить
- `percent` - процент выполнения (0-100)
- `isCompleted` - достигнута ли цель (100%)

**Методы:**
- `toJson()` - конвертация в JSON для Firebase
- `fromJson()` - создание из Firebase JSON
- `copyWith()` - создание копии с изменениями

### 2. Сервис управления целями (`lib/services/goal_service.dart`)

**Firebase интеграция:**
- Хранение целей: `/parents_children/{parentKey}/{childId}/goals/{goalId}`
- Real-time listener для автоматического обновления
- Broadcast stream для подписки компонентов UI

**Основные методы:**
- `createGoal()` - создание новой цели с валидацией
- `depositToGoal()` - пополнение цели
- `completeGoal()` - автоматическое завершение при достижении 100%
- `abandonGoal()` - отказ от цели
- `activeGoal` - получение текущей активной цели
- `allGoals` - получение всех целей (истории)
- `goalsStream` - поток для real-time обновлений

**Валидация:**
- Название не пустое
- Сумма > 0
- Срок в будущем (если указан)
- Только одна активная цель одновременно

### 3. Анимация достижения цели (`lib/widgets/celebration_animation.dart`)

**Функционал:**
- Анимация конфетти при достижении 100%
- Диалог поздравления с иконкой трофея
- Автоматическое воспроизведение анимации в течение 3 секунд
- Плавное закрытие диалога

**Компоненты:**
- `CelebrationAnimation` - виджет анимации конфетти
- `ConfettiPainter` - кастомный painter для отрисовки конфетти
- `showCelebrationDialog()` - функция показа диалога

### 4. Экран истории целей (`lib/screens/goals_history_screen.dart`)

**Функционал:**
- Отображение всех целей (активных и завершённых)
- Сортировка: сначала активные, потом по дате создания
- Карточки с подробной информацией о каждой цели
- Статусы: Активна / Завершена / Отменена
- Период накопления для завершённых целей

**Отображаемая информация:**
- Название и целевая сумма
- Прогресс-бар (линейный)
- Процент выполнения
- Накопленная сумма из целевой
- Даты: создания, срок, завершения
- Период накопления (для завершённых)

### 5. Обновлённый диалог создания цели (`lib/screens/dialogs.dart`)

**Новые возможности:**
- Выбор срока достижения цели (DatePicker)
- Локализация календаря (ru_RU)
- Возможность удалить выбранный срок
- Улучшенная валидация
- Возврат всех данных (name, target, deadline)

### 6. Интеграция в главный экран ребёнка (`lib/screens/child_home_screen.dart`)

**Изменения:**
- Использование `GoalService` вместо прямого Firebase
- Real-time подписка на изменения целей
- Автоматическая анимация при достижении цели
- Улучшенный UI для отображения целей

**Состояния:**
1. **Нет цели** - кнопка "Создать цель"
2. **Активная цель (в процессе)** - прогресс, кнопки "Внести" и "Отказаться"
3. **Завершённая цель** - зелёный фон, кнопка "Новая цель"

**Отображение прогресса:**
- Круговой индикатор прогресса (CircularProgressIndicator)
- Процент выполнения в центре
- Накоплено / Целевая сумма
- Осталось накопить
- Срок (если указан)

**Навигация:**
- Кнопка "История" → `GoalsHistoryScreen`
- Подтверждение при отказе от цели

### 7. Обновлённый экран целей (`lib/screens/goals_tab.dart`)

**Функционал:**
- Полная поддержка нового GoalService
- Real-time обновления через Stream
- Celebration animation при достижении цели
- История целей через AppBar action

**UI:**
- Большой круговой прогресс-бар (160x160)
- Информация: накоплено / осталось
- Кнопки в зависимости от статуса цели
- Пустое состояние с призывом создать цель

## Firebase структура

```
/parents_children
  /{parentKey}
    /{childId}
      /balance: 1000
      /name: "Маша"
      /goals
        /{goalId1}
          /id: "goalId1"
          /name: "Велосипед"
          /target: 5000
          /progress: 2500
          /active: true
          /createdAt: "2024-01-15T10:00:00.000Z"
          /deadline: "2024-06-01T00:00:00.000Z"
        /{goalId2}
          /id: "goalId2"
          /name: "Планшет"
          /target: 3000
          /progress: 3000
          /active: false
          /createdAt: "2023-12-01T10:00:00.000Z"
          /completedAt: "2024-01-10T15:30:00.000Z"
      /history
        /{historyId}
          /action: "Создание цели"
          /amount: 0
          /note: "Велосипед"
          /timestamp: "2024-01-15T10:00:00.000Z"
```

## Критерии приемки (выполнено)

✅ 1. **Создание цели сохраняется в Firebase и синхронизируется в реальном времени**
   - Использование Firebase Realtime Database
   - Real-time listeners для автоматического обновления

✅ 2. **Прогресс-бар обновляется при любом изменении баланса**
   - StreamBuilder подписан на goalsStream
   - Автоматическое обновление UI при изменениях в Firebase

✅ 3. **При 100% - анимация и смена статуса на "завершено"**
   - Celebration dialog с конфетти
   - Автоматическое завершение цели в GoalService
   - Запись в историю операций

✅ 4. **История целей отображается полностью и правильно сортируется**
   - Отдельный экран GoalsHistoryScreen
   - Сортировка: активные первые, затем по дате
   - Карточки с полной информацией

✅ 5. **Данные не теряются при переоткрытии приложения**
   - Хранение в Firebase Realtime Database
   - Persistence включён по умолчанию

✅ 6. **UI адаптивен под разные размеры экранов**
   - Responsive layout с SingleChildScrollView
   - Flexible виджеты для адаптивности
   - Минимальные размеры для кнопок

## Технические детали

### Зависимости
- `firebase_database` - Firebase Realtime Database
- `intl` - форматирование дат
- `google_fonts` - шрифты Nunito

### Паттерны и практики
- **Singleton service** - один экземпляр GoalService на пару (parentKey, childId)
- **Stream-based architecture** - reactive обновления UI
- **Future-based async operations** - для Firebase операций
- **Proper cleanup** - dispose методы для отмены подписок
- **mounted checks** - безопасное использование BuildContext

### Real-time обновления
1. Firebase изменяет данные
2. `onValue` listener получает событие
3. GoalService парсит данные и обновляет _cachedGoals
4. Новый список отправляется в Stream
5. UI компоненты (StreamBuilder) автоматически обновляются
6. При завершении цели показывается анимация
